What is Unsupervised Learning?

Unsupervised learning is a type of machine learning where the algorithm learns patterns from unlabeled data — data without predefined categories or correct answers. Unlike supervised learning, there is no teacher guiding the process. The algorithm explores the data's inherent structure on its own.

The goal is to discover hidden patterns, groupings, or representations within the data. Common tasks include clustering (grouping similar items), dimensionality reduction (compressing features), and anomaly detection.

Supervised: f(X) → Y (labeled) Unsupervised: f(X) → ? (structure discovery)

🔴
What is Clustering?

Clustering is the process of grouping data points so that objects in the same group (cluster) are more similar to each other than to those in other groups. Similarity is typically measured using a distance metric.

Clustering is widely used for customer segmentation, image compression, document grouping, and biological taxonomy. There is no ground truth — the algorithm defines what "similar" means.

⚙️
What is K-Means?

K-Means is the most popular clustering algorithm. It partitions n observations into K clusters, where each observation belongs to the cluster with the nearest centroid (cluster mean).

The algorithm minimizes the within-cluster sum of squares (WCSS), also called inertia:

WCSS = Σ Σ || x_i − μ_k ||²

where μ_k is the centroid of cluster k and x_i is a data point assigned to that cluster.

🎯
Centroids

A centroid is the arithmetic mean of all data points belonging to a cluster. It acts as the "center" or representative point of the cluster. Centroids are not necessarily actual data points — they are computed values.

μ_k = (1 / |S_k|) · Σ x_i for all x_i in cluster k

At each iteration, centroids are recalculated based on the current cluster assignments, causing them to shift toward the true center of each group.

📏
Distance Metrics — Euclidean Distance

K-Means uses Euclidean distance to measure similarity between a data point and a centroid. For two points P = (x₁, y₁) and C = (x₂, y₂):

d(P, C) = √[ (x₁−x₂)² + (y₁−y₂)² ]

For n features: d(P, C) = √[ Σ (P_i − C_i)² ]

⚠️ Important: When features have different scales (e.g., age 1–65 vs. income 1,000–100,000), the larger-scale feature dominates the distance. Always normalize or standardize your data before applying K-Means.

🔄
Iterative Process

  • 1
    Initialize: Randomly place K centroids in the feature space (or select K data points).
  • 2
    Assign: Calculate the distance from each data point to every centroid. Assign each point to the nearest centroid.
  • 3
    Update: Recalculate each centroid as the mean of all points assigned to it.
  • 4
    Check: If centroids have moved, go back to step 2. If centroids are stable (or change is below threshold), stop.
  • 5
    Result: The algorithm has converged to a local minimum of the WCSS objective.

📉
Variance and Convergence

Variance (or WCSS/inertia) measures how compact the clusters are. A lower variance means data points are closer to their centroids — tighter, more defined clusters.

Variance = (1/n) · Σ d(x_i, μ_k(i))²

K-Means is guaranteed to converge because: (1) there are finite possible cluster assignments, and (2) each step (assign + update) either decreases WCSS or keeps it the same. However, it may converge to a local minimum, not the global one. Running the algorithm multiple times with different initializations (K-Means++) helps.
