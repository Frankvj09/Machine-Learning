📊 Logistic Regression: Basic Concepts

Understanding logistic regression for binary classification problems

What is Logistic Regression?

Logistic regression is a statistical method used for binary classification problems. Unlike linear regression which predicts continuous values, logistic regression predicts the probability that an instance belongs to a particular class (0 or 1). It uses a sigmoid function to map any real-valued number into a value between 0 and 1.

P(y=1|x) = 1 / (1 + e^-(β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ))
Where:
• P(y=1|x) = probability of belonging to class 1
• β = coefficients (weights)
• x = input features
• e = Euler's number

Types of Machine Learning

Supervised Learning

Data with labels. Logistic regression is a supervised learning algorithm.

Unsupervised Learning

Data without labels. Finds patterns in unlabeled data.

Reinforcement Learning

Learning through rewards and penalties.

Classification vs Regression

Regression:
• Predicts continuous values
• Examples: price, temperature, salary
• Output: any real number

Classification:
• Predicts discrete categories
• Examples: spam/not spam, purchase/no purchase
• Output: 0 or 1 (binary) or multiple classes
Our Example: Predicting whether a customer will purchase a product (binary classification)

The Sigmoid Function (S-Curve)

The sigmoid function transforms linear regression output into a probability between 0 and 1. The decision threshold is typically 0.5:

f(z) = 1 / (1 + e^-z)
Where z = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ
Interpretation:
• If probability ≥ 0.5 → predict class 1 (Purchase)
• If probability < 0.5 → predict class 0 (No Purchase)

Data Preparation

  • Load Data: Import dataset (CSV, Excel, etc.)
  • Explore Data: Check structure, statistics, missing values
  • Separate Variables: X (features) and y (target)
  • Train-Test Split: Usually 80% training, 20% testing
  • Standardization: Scale features to have mean=0, std=1 (recommended for logistic regression)
Our Dataset Features:
• edad (age)
• ingreso_mensual (monthly income)
• visitas_web_mes (web visits per month)
• tiempo_sitio_min (time on site in minutes)
• compras_previas (previous purchases)
• descuento_usado (discount used: 0/1)
• target (target: 0=no purchase, 1=purchase)

Training the Model

The model learns coefficients (weights) that best separate the classes using Maximum Likelihood Estimation (MLE). The algorithm finds parameters that maximize the likelihood of observing the training data.

Log-Likelihood Function:
L(β) = Σ[yᵢ·log(p(xᵢ)) + (1-yᵢ)·log(1-p(xᵢ))]

Confusion Matrix

The confusion matrix shows the performance of the classification model:

Predicted: NO Predicted: YES
Actual: NO TN (True Negative) FP (False Positive)
Actual: YES FN (False Negative) TP (True Positive)
Key Metrics:
• Accuracy: (TP + TN) / Total
• Precision: TP / (TP + FP) - How many predicted positive are actually positive
• Recall: TP / (TP + FN) - How many actual positives were correctly identified
• F1-Score: 2 * (Precision * Recall) / (Precision + Recall)

ROC Curve & AUC

The ROC (Receiver Operating Characteristic) curve shows the trade-off between True Positive Rate and False Positive Rate. AUC (Area Under the Curve) measures the model's ability to distinguish between classes:

AUC Interpretation:
• 0.90-1.00: Excellent classification
• 0.80-0.90: Good classification
• 0.70-0.80: Fair classification
• 0.60-0.70: Poor classification
• 0.50-0.60: No better than random

Real-World Application: Customer Purchase Prediction

Business Problem: E-commerce company wants to predict which customers will purchase a product to target marketing campaigns effectively.

Data Collected: Age, income, website behavior, previous purchases, discount usage.

Model Output: Probability of purchase (0-1). Customers with probability > 0.5 receive targeted promotions.

Business Impact: Companies using logistic regression for customer targeting typically see 20-40% improvement in marketing ROI by focusing on high-probability customers.

Key Takeaways

  • ✓ Logistic regression is used for binary classification (yes/no, purchase/no purchase)
  • ✓ Uses sigmoid function to output probabilities between 0 and 1
  • ✓ Decision threshold typically 0.5 (can be adjusted for business needs)
  • ✓ Data standardization improves model performance
  • ✓ Confusion matrix helps evaluate classification performance
  • ✓ ROC-AUC measures overall model discrimination ability
  • ✓ Interpretable model - coefficients show feature importance
