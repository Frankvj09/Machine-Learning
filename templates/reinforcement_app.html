Reinforcement Learning Application

Simulation of rewards and agent learning

Problem Description

The objective of this simulation is to demonstrate how an agent learns through rewards and penalties.

The agent performs actions and accumulates rewards across multiple episodes.

Environment

The environment represents the space where the agent interacts.

At every step, the agent selects an action and receives feedback.

Reward Mechanism

Positive actions generate rewards, while poor actions may generate penalties.

Reward Range: -5 to 10

Episodes

The simulation was executed for 100 episodes.

During each episode, the agent performed multiple actions.
